# 🤖 Gemini AI ChatBot

## 💼 Project Type

Personal Frontend Project

Built an AI-powered chatbot interface using the Google Gemini API that provides real-time AI conversations through a clean and responsive chat interface.

---

# 🌍 About The Project

Gemini AI ChatBot is a responsive web application that allows users to interact with Google's Gemini AI using natural language prompts.

The project focuses on frontend development, API integration, asynchronous JavaScript, responsive layouts, and creating a modern chat user interface.

# ✨ Features

- AI-powered conversations using Google Gemini API
- Real-time AI response generation
- Responsive chat interface
- Auto-scrolling chat window
- Loading animation while waiting for responses
- Dynamic chat rendering
- Clean and modern UI
- Mobile-friendly design
